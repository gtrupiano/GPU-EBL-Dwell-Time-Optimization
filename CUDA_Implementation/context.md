# Context for Project
Information regarding what the goal of the project is as well as what was done to get it working properly.

## Notes
1. **Create a `output_data` folder before running program in order for data to be properly stored**
2. IC layout needs to be a 1 channel .ppm image
    - Convert any image into the required `P5` .ppm with `convert_ic_to_ppm.py`
3. The PSF mask must be a normalized 65x65 `.raw` file.
   - Generate the PSF `.npy` with the Python proof of concept.
   - Convert it with `convert_psf_to_raw.py`.
   - The converter normalizes the PSF and converts its values to `float32`.
4. The CUDA output is a `.raw` file.
   - Convert a PSF or dwell-time `.raw` file into a viewable PNG with
     `convert_raw_to_png.py`.
   - Generated PNG files default to the CUDA `output_data` folder.

## Task
1. Setup environment on local machine
2. Implement algorithm and kernels for `GPU EBL Dwell Time Optimization`.
3. Setup host code and execute kernels
   - Allocate GPU memory
   - Copy memory from CPU to the GPU
   - Create algorithm
     - Using / launching GPU kernels
   - Copy the GPU memory back to the CPU
   - Free the GPU memory
4. Build and run implementation of CUDA program.

## Execution
1. Since CUDA v12 (my GPU CUDA version) doesn't support GCC v13 (my machines GCC version), I needed to modify the CMAKE in order for it to compile properly.

    Added this to CMake before `find_package(CUDA REQUIRED)`:
    ```
    if(EXISTS /usr/bin/g++-12)
        set(CUDA_HOST_COMPILER /usr/bin/g++-12 CACHE FILEPATH "CUDA host compiler" FORCE)
    endif()
    ```

2. Implemented algorithm and kernels for `GPU EBL Dwell Time Optimization`.

3. Setup the host code.

4. In order to run the CUDA programs, the following steps need to be followed.
    1. Create a build folder inside the example.
    2. Run the CMake from build folder.
        - Make sure the name of the CUDA program is correct in the CMake.
    3. Run the Make generated by the CMake.
        - This will generate the executable of the CUDA program.
    4. Run the executable for `GPU_EBL_Dwell_Time_Optimization`.
        - Passing in the target IC layout and PSF mask input datasets.
        - Example of how to run executable with proper arguments:
            ```
            ./build/GPU_EBL_Dwell_Time_Optimization -i "./input_data/IC128.ppm,./input_data/PSF_Mask_65x65.raw" -t image
            ```
